# Security Policy

EnvShape CLI exists to reduce accidental environment-variable drift and secret
exposure. Please report security issues privately before opening a public issue.

## Supported Versions

The `main` branch receives security fixes while the project is in early
development.

## Reporting a Vulnerability

If you find a vulnerability, please open a private security advisory on GitHub
or contact the maintainer through the repository profile. Include:

- a short description of the issue
- steps to reproduce
- expected and actual behavior
- whether any secret value could be exposed

Please do not include real secrets in reports or examples.
