# Changelog

## 0.1.1

- Added `envshape-cli` as a command alias so `npx envshape-cli@latest` works
  directly.
- Documented npm install and direct `npx` usage.

## 0.1.0

- Added zero-dependency dotenv parsing.
- Added `check`, `generate`, and `list` commands.
- Added CI workflow and Node test coverage.
- Added safe `.env.example` generation that avoids copying secret-like values.
