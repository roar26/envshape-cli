# Roadmap

EnvShape is early-stage software. The current focus is to keep the core tool
small, dependable, and easy for open source maintainers to adopt.

## Near Term

- Publish a stable `v0.1.0` release after initial user feedback.
- Add more parser fixtures for quoted values, escaped values, and comments.
- Document framework-specific examples for Next.js, Vite, and Express.
- Add a rule reference with examples for every error and warning.

## Next

- Add optional schema output for documentation generators.
- Add typed rule configuration without requiring a separate config file.
- Improve GitHub Action examples for monorepos.
- Add Windows and macOS examples to the CI documentation.

## Later

- Explore adapters for framework-specific environment conventions.
- Add integration examples for popular secret scanning tools.
- Consider publishing package provenance metadata when the npm package is
  released.
